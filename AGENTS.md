# Public release boundary

This repository contains reusable Skill code and wholly fictional examples only.

Before every commit intended for publication, release upload or catalog submission, read `docs/publishing.md` and complete its privacy review against the exact outgoing files. This applies to every person's data, including the publisher and anyone who uses the Skill.

Never publish personal records, real transaction excerpts, identity/contact/account information, credentials, private URLs, saved personal settings, reports, logs, caches, or screenshots derived from those materials. Examples must be invented from scratch, not anonymized real records. Do not read a private project to source public examples or to populate a privacy denylist.

Review code, documentation, fixtures, images, metadata and upload form text. A handoff assertion, passing tests, `.gitignore`, an allowlist or an automated scan alone is not content approval. Resolve suspicious material before uploading. Retain legally required public license attribution; do not confuse that with user business data.

Record the reviewed file list and artifact hashes in local release evidence outside this repository. If outgoing content changes, recheck the affected content before uploading. Catalog acceptance does not establish public availability or matching package contents.
