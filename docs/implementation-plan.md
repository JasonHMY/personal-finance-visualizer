# Version 1

Build an Agent Skill with a standalone local report, fictional examples and equivalent English and Chinese documentation.

- Use original, dependency-free HTML/CSS/JavaScript and Python standard-library code.
- Accept normalized JSON or CSV. Bank-specific PDF extraction remains an agent task with reconciliation before visualization.
- Process reports in memory by default; export only on explicit request. No telemetry, remote assets, bank connection, or automatic update requests.
- Keep bank-date cash movement separate from personal spending, confirmed refunds and shared expenses.
- Provide English and Chinese controls, four views, four time scales, transaction drill-down and collapsed explanations.
- Verify calculation invariants, untrusted strings, local delivery, export, synthetic provenance and package contents.
- Publish a tagged GitHub release and the supported skill registry package; verify each result separately.

The public package contains no source bank statements or personal financial records. All demo records are invented.
