# Personal Finance Visualizer 图文详解

[English](visual-guide.md) · [项目首页](../README.zh-CN.md) · [安装](../README.zh-CN.md#安装为-agent-skill) · [输入格式](../skills/personal-finance-visualizer/references/schema.md)

这里展示的是 1.3.0 版内置界面。全部截图使用同一份完全虚构的美元数据，是实际报表截图，不是设计稿。点击图片可查看原图。

## 消费：先看整体，再看分类

第一排展示本人总花费、日常支出和日均生活费；第二排分别展示固定服务、AI 服务和租房。圆环中心是总额，下方列表列出各扇区对应的金额。

通过标题旁的按钮切换视图。按天、周、月、年控件调整统计期间；上一期、下一期和日期选择器用于浏览现有数据。未完整覆盖的期间只统计到已确认的截止日。

![英文消费页的三张主要圆环和三张分组圆环](../demo/expenses-en.jpg)

## 商户细分：一类花费去了哪里

主要圆环下方保留日常商户卡片，进一步检查各商户。图中展示超市、餐饮和购物。待分类、交通和其他日常类别即使不出现在下方商户区，也仍保留在主要总额和交易明细中。

趋势图按天展示日常支出，年视图改为按月汇总。可以切换面积或柱状图，点击数据点或柱形可查看对应日期或月份的交易。

![商户圆环和日常消费趋势](../demo/merchants-en.jpg)

## 交易明细：查看原始金额

点击圆环扇区或圆环下方的分类行，即可打开对应交易。窗口保留期间、笔数和总额，支持展开式搜索、分类及账户筛选、表头排序、筛选合计与连续滚动。

每行保留银行原始金额、本人比例、本人支出和来源凭据。已确认的分摊比例只影响消费统计，原始银行金额仍可查看。金额显示时的舍入，可能使逐行显示值的合计与未舍入总额存在小额尾差。

![虚构商户的交易、来源凭据及分摊比例](../demo/transaction-details-en.jpg)

## 收入：总额、日均和来源

两张主要圆环显示总收入和每个有效覆盖日的平均收入。下一排分别展示已确认的工资、生活费汇入和其他收入，趋势图展示到账时间。

转入不会自动被认作收入。用途不明的入账先保留在转账中，直到用途确认。本人账户调拨和消费退款不计收入。

![收入页的来源分类和每日趋势](../demo/income-en.jpg)

## 转账：资金往来与已确认归还

对外转出和转入分别展示圆环，下方三项指标显示净转出、已核对归还和已确认借款未还金额。图中的月视图展示三月，演示资料覆盖 1—3 月。

只有明确归类为借款的记录才进入借款指标。已确认的结算分配会抵消相关转出和转入；部分归还后保留余款。仅凭姓名、日期或金额相似不会自动配对。

![对外转出、转入圆环和已确认借款指标](../demo/transfers-en.jpg)

## 收支总览：已提供账户的资金变化

总览展示总流入、总流出和净增减，点击指标可检查对应流水。它按银行入账日统计，排除本人账户调拨，并应用已确认的转账抵消。

消费和资金变动回答不同的问题。已确认退货可以在消费中抵消原购买，而两笔实际入账仍保留在资金视图中。该页不计算银行余额或完整净资产。

![虚构三月期间的资金总览](../demo/overview.jpg)

## 需要时再看说明

鼠标悬浮或键盘聚焦信息图标，可查看对应卡片的定义。先展开底部“更多信息”，再打开“说明”，可查看日均分母、消费口径、退款、转账及资料限制。明细和说明默认收起。

日均数包含覆盖期间内零消费的自然日。数据缺口和不确定分类应保留在报表说明中，不应悄悄补齐。

![展开后的计算口径和来源说明](../demo/notes-en.jpg)

## 中文、浅色主题和小屏幕

语言选择器可在英文和简体中文控件之间切换。除非另行指定，Agent 按你的请求语言回应。原始交易说明和商户名称保留输入内容；切换界面语言不会改写交易记录。

![中文消费界面](../demo/expenses-zh.jpg)

主题按钮可以在本地切换深色和浅色，不发起网络请求。

![浅色主题消费页](../demo/expenses-light-en.jpg)

窄屏下卡片排列为一列，控件自动换行。交易表格可横向滚动，保留所有字段。

<img src="../demo/mobile-en.jpg" alt="窄屏下的消费页面" width="360">

## 试用这套界面

在仓库根目录运行内置演示，再打开命令输出的本地地址：

```bash
python3 skills/personal-finance-visualizer/scripts/report.py --demo --language en
```

命令运行期间，报表保留在进程内存中；结束后按 Ctrl+C 停止。使用自己的记录时，按[输入格式](../skills/personal-finance-visualizer/references/schema.md)和[核对流程](../skills/personal-finance-visualizer/references/workflow.md)处理。只有决定保留本地报表时才导出。

独立报表不含远程资源或分析服务。Agent 宿主如何处理提示词和提供的文件取决于其设置，见[隐私与边界](../README.zh-CN.md#隐私与边界)。报表模板不包含 ChatGPT 宿主的编辑、Ask ChatGPT 和发布工具。
